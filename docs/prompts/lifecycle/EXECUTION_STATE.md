# Execution State Prompt

After Master System Design approval.

```text
Read AGENTS.md, the Builder workflow, official rules when supplied, approved problem.md and plan.md, state files, and repository evidence. Initialize or reconcile execute.md and review.md only where verified evidence supports it.

Track objective, Golden-Path relationship, owners, dependencies, relevant contract, involved layers or N/A, risk, branch/worktree, Builder status, local verification, PR/CI/review, merge/synchronization/rendezvous/QA state, evidence, blockers, next action, and deferrals. Do not implement product behavior, change architecture, commit, or push.
