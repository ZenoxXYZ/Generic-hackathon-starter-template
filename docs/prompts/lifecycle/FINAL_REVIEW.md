# Final Review Prompt

## Use

Before demonstration or delivery.

```text
Read AGENTS.md, docs/REPO_REVIEW_WORKFLOW.md, official rules when supplied, approved state files, phase/review evidence, code, tests, migrations, configuration, deployment records, public URLs if present, and Git evidence. Run a read-only final repository review for [CHECKPOINT].

Prioritize rules, startup, Golden Path, correctness, persistence/state, frontend/backend compatibility, selected release evidence, validation/error behavior, test evidence, configuration, and P0/P1 findings. Distinguish local from deployed verification. Classify findings and stop without fixing, committing, or pushing.
```
