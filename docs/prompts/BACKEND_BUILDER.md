# Backend Builder Prompt

Follow the Builder prompt for one backend-oriented workstream. Inspect affected contracts, schemas, services, logic, persistence, migrations, configuration, and tests. Keep HTTP concerns in routes and business/decision behavior out of routes. Escalate material API, schema, invariant, or dependency changes before implementing them.

For material corrective planning, use [Corrective Workstream](lifecycle/CORRECTIVE_WORKSTREAM.md).
