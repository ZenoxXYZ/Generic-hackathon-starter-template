# Builder Prompt

Read `AGENTS.md`, `docs/AGENT_WORKFLOW.md`, relevant HADF guides, approved state files, code, tests, migrations, configuration, and Git evidence. Plan one approved bounded workstream with scope, Golden-Path relevance, contracts, dependencies, risks, verification, evidence, and deferrals. Stop for human approval. After approval, implement only that scope; report changed files, verification, failures, and unverified items without committing or pushing.

Use [Builder plan-only](lifecycle/BUILDER_PLAN_ONLY.md), [implementation approval](lifecycle/IMPLEMENTATION_APPROVAL.md), and [Builder closeout](lifecycle/BUILDER_CLOSEOUT.md) for detailed lifecycle handoffs.
