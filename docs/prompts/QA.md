# QA Prompt

Inspect the approved workstream, Golden Path, relevant contracts, real implementation, and existing verification. Verify behavioral success, important failures, boundaries, integration risks, and the selected runtime path. State what is proven, failed, deferred, and not verified. Do not claim E2E from unit or CI evidence alone.

Use [Integration Rendezvous](lifecycle/INTEGRATION_RENDEZVOUS.md) and the [E2E runbook](../runbooks/E2E.md) for assembled-flow checks.
