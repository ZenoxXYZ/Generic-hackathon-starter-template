# Builder Launch

The Builder first inspects `AGENTS.md`, approved state files, relevant code, tests, migrations, configuration, Git evidence, and applicable HADF guides. It proposes a bounded plan covering scope, contracts, layers, risks, tests, evidence, deferrals, and exit criteria.

After explicit approval, the Builder implements only that scope, self-verifies, records evidence, and escalates material architecture, API, schema, invariant, dependency, MVP, or Golden-Path changes.

Use [Builder prompts](../prompts/BUILDER.md) and the detailed [Builder workflow](../AGENT_WORKFLOW.md).
