# Workstream Start

1. Confirm the workstream exists in approved `plan.md` and has prerequisites.
2. Record objective, Critical-Proof-Path relevance, Primary Owner, optional contributors, dependencies, governing Interface / Assumption Contracts, required evidence, integration applicability, and exit criteria in `execute.md`. Record Golden-Path relevance only for Product Build work.
3. Synchronize `main`.
4. Create one bounded branch.
5. Decide whether concurrent mutable work requires a dedicated worktree.
6. Launch a Builder planning pass; do not implement until human approval.
