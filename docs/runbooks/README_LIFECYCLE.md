# README Lifecycle

The README begins as generic template orientation. After `problem.md` and `plan.md` are approved and `execute.md` is initialized, transition it to the actual challenge: project summary, MVP, Golden Path, architecture, setup, environment, tests, and verified status.

After Golden-Path implementation stabilizes, reconcile it against code, tests, migrations, runtime behavior, selected release path, deployment evidence if used, limitations, and deferrals. Do not claim planned behavior as implemented.
