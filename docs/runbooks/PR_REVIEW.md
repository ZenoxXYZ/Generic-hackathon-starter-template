# PR Review

1. Verify the PR describes one bounded workstream and its approved contract.
2. Read the diff and evidence; do not rely only on the author summary.
3. Distinguish CI results from review judgment.
4. Check scope, architecture, contract compatibility, tests, risks, and required follow-up.
5. Record a verdict: approve, request changes, or accept documented non-blocking follow-up.
6. Merge only when the human authorizes it.
